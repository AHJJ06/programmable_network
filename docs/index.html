What I learned

Where are the data, control and management planes in your network?

The data plane is in the switches and host network interfaces that forward packets. The control plane is in the switches' MAC-learning and forwarding logic. The management plane is where the topology defined and managed using the YAML file and Python scripts.

How did your switches learn which port leads to each host? Use your MAC table evidence.

The switches leraned MAC addresses by examining the source MAC addresses of incoming Ethernet frames and recording them with the incoming port. The MAC table of s1 shows that ports 1 and 2 learned addresses 00:00:00:00:00:01 and 00:00:00:00:00:02, corresponding to hosts h1 and h2. Port 3 learned addresses for h3 to h6 through the connection to s2, showing that the switch leraned which port leades to the other hosts.

Which of the four kinds of programmability is this assignment (a network described as data, then built and documented by scripts)? Why isn't it any of the other three?

This assignment is automated configuration management because the network is described as data and built and checked using scripts. It is not a programmable data plane because we do not change how switches process packets, an externalised control plane because we do not use a centralised controller to make forwarding decisions, or programmatic device interfaces because the main focus isnot communicating with devices thorugh structured APIs.

Week 1's 2 a.m. change on 40 switches: what would be different if those switches were described like your network?

Instead of manually changing 40 switches one by one at 2 a.m., an engineer could update the network description and use scripts to apply the changes automatically and consistently, reducing human errors.

What's the difference between your network's data model and its serialisation? Use YAML and JSON as the example.

The data model is the structure of the information such as hosts, switches, Ip addresses and links while serialization is how that information is represented in a file. YAML and JSON can represent the same network data model using different formats.

Why is it better to catch bad data in check() than with pingall? What did IPv6 notice about a duplicate address that IPv4 didn't?

The check() function detects configuration problems before the network is built, making errors easier to identify and fix. pingall tests connectivity. IPv6 Duplicate Address Detection can detect an address conflict during address configuration, whereas IPv4 does not automatically report duplicate address

What does your Git history give you that copying files into folders named topology-v2-final wouldn't?

Git history records every commit with its changes and message, allowing us to compare versions, track changes, and restore previous versions easily. Unlike copying folders, Git keeps everything in one repository with a clear history.
